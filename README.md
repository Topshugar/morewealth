# MoreWealth

MoreWealth is a premium, global-first financial education and planning website. The launch experience is intentionally education-first: it does not offer investment management, custody, brokerage, trade execution, or investment recommendations.

## Version 1

- Responsive premium landing page
- Financial education pathways
- Planning-service positioning
- Educational savings tool
- Country availability selector
- Interest form with client-safe language
- Educational and jurisdictional disclosure language

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Important

The current forms are front-end demonstrations and do not send data to a backend. Legal, regulatory, privacy, and disclosure content must be reviewed and localized before accepting real users or client information.
