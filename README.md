# MoreWealth

MoreWealth is a premium, global-first financial education and planning website. The launch experience is intentionally education-first: it does not offer investment management, custody, brokerage, trade execution, or personal investment recommendations.

## Version 1

- Responsive premium landing page
- Financial education pathways
- Planning-service positioning
- Educational savings tool
- Country availability selector
- Interest form with client-safe language
- Educational and jurisdictional disclosure language

## Education and planning library

- `education.html` — filtered learning-center cards covering foundations, planning, investing, and life stages
- `planning.html` — an in-browser, three-question educational planning starting point
- `tools.html` — emergency-fund and hypothetical savings calculators

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Important

The forms and planning interactions are front-end demonstrations and do not send data to a backend. Legal, regulatory, privacy, and disclosure content must be reviewed and localized before accepting real users or client information.
